# رفيق المعلم

منصة أدوات صفية تفاعلية للمعلم العربي، مصممة للعرض على شاشة العرض والسبورة الذكية. أحد مشاريع رافد.

## المرحلة الحالية

واجهة ثابتة (HTML + CSS + JavaScript) تعمل على أي استضافة بدون خطوة بناء:

| الصفحة | الملف | الحالة |
|---|---|---|
| الرئيسية + الباقات | `index.html` | جاهزة (الأسعار لم تُحدَّد) |
| لوحة الأدوات + اختيار الصف الحالي | `tools.html` | جاهزة |
| صفوفي (قاعدة بيانات الصفوف والطلاب، استيراد إكسل) | `classes.html` | جاهزة، التخزين في المتصفح مؤقتًا |
| من نحن | `about.html` | جاهزة |
| تسجيل الدخول / حساب جديد | `login.html` | واجهة فقط، بانتظار الخادم |
| اختيار الطالب: 9 طرق (مرتبطة بالصفوف) | `tools/picker.html` | جاهزة، مجانية |
| مؤقت الأنشطة | `tools/timer.html` | جاهز، مجاني |

## البنية

```
assets/css/main.css      الهوية والأنماط المشتركة (ألوان رافد، خطوط Zain و Readex Pro، الوضع الداكن)
assets/css/tool.css      أنماط صفحات الأدوات (المسرح، ملء الشاشة، اللوحات)
assets/js/layout.js      الترويسة وقائمة الصفحات والتذييل (مكان واحد لكل الصفحات)
assets/js/common.js      التخزين المحلي، الأصوات، ملء الشاشة
assets/js/classes-store.js  بيانات الصفوف والطلاب، الاستيراد، الصف الحالي
assets/js/audio-library.js  أصوات مؤقت الأنشطة: المقاطع الجاهزة + ما يرفعه المعلم (IndexedDB)
assets/audio/            المقاطع الجاهزة للمؤقت (تُولَّد بـ scripts/generate-timer-audio.py)
assets/vendor/xlsx.full.min.js  مكتبة SheetJS لقراءة ملفات الإكسل (نسخة محلية)
assets/js/picker-modes.js  طرق اختيار الطالب (الكشاف، الشريط، الشبكة، ...)
assets/js/tools-data.js  قائمة الأدوات وتصنيفها (مجانية / للمشتركين)
tools/                   صفحة مستقلة لكل أداة
```

## إضافة أداة جديدة

1. أنشئ صفحتها داخل `tools/` (انسخ هيكل `tools/timer.html` كنقطة بداية).
2. أضف عنصرًا في `assets/js/tools-data.js` مع `tier: 'free'` أو `tier: 'pro'`.

## ملف الإكسل المطلوب لصفحة صفوفي

أعمدة: `اسم الطالب`، `الصف`، `الشعبة` (بأي ترتيب، ويمكن أن يسبقها سطر عنوان).
عند رفع ملف جديد تُستبدل قائمة كل صف موجود في الملف، وتبقى الصفوف الأخرى كما هي.

> ملاحظة: نسخة SheetJS الحالية (0.18.5 من npm) قديمة. عند النشر يُفضّل استبدالها بآخر نسخة من
> `https://cdn.sheetjs.com` (مثل 0.20.3) بنفس المسار `assets/vendor/xlsx.full.min.js`.

## أصوات مؤقت الأنشطة

- وضع «تنبيهات المؤقت»: دقات في آخر 10 ثوانٍ، أشد في آخر 3، ثم صوت الانتهاء.
- وضع «أنشودة أو مقطع»: يبدأ المقطع مع المؤقت، يتكرر حتى ينتهي الوقت، ثم يتوقف تدريجيًا.
- لإضافة أنشودة جاهزة لكل المستخدمين: ضع الملف (mp3 مثلًا) في `assets/audio/`
  وأضفه إلى `BUILTINS` في `assets/js/audio-library.js`. تأكد من امتلاك حق استخدامها.

## التشغيل محليًا

```
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## المراحل القادمة

- ربط الحسابات (تسجيل الدخول، حفظ قوائم الفصول على الحساب).
- الباقات والدفع وقفل الأدوات المدفوعة.
- أدوات جديدة.
