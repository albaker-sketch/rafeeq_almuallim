# رفيق المعلم

منصة أدوات صفية تفاعلية للمعلم العربي، مصممة للعرض على شاشة العرض والسبورة الذكية. أحد مشاريع رافد.

## المرحلة الحالية

واجهة ثابتة (HTML + CSS + JavaScript) تعمل على أي استضافة بدون خطوة بناء:

| الصفحة | الملف | الحالة |
|---|---|---|
| الرئيسية + الباقات | `index.html` | جاهزة (الأسعار لم تُحدَّد) |
| لوحة الأدوات | `tools.html` | جاهزة |
| تسجيل الدخول / حساب جديد | `login.html` | واجهة فقط، بانتظار الخادم |
| عجلة الأسماء | `tools/wheel.html` | جاهزة، مجانية |
| مؤقت الأنشطة | `tools/timer.html` | جاهز، مجاني |

## البنية

```
assets/css/main.css      الهوية والأنماط المشتركة (ألوان رافد، خطوط Zain و Readex Pro، الوضع الداكن)
assets/css/tool.css      أنماط صفحات الأدوات (المسرح، ملء الشاشة، اللوحات)
assets/js/common.js      التخزين المحلي، الأصوات، ملء الشاشة
assets/js/tools-data.js  قائمة الأدوات وتصنيفها (مجانية / للمشتركين)
tools/                   صفحة مستقلة لكل أداة
```

## إضافة أداة جديدة

1. أنشئ صفحتها داخل `tools/` (انسخ هيكل `tools/timer.html` كنقطة بداية).
2. أضف عنصرًا في `assets/js/tools-data.js` مع `tier: 'free'` أو `tier: 'pro'`.

## التشغيل محليًا

```
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## المراحل القادمة

- ربط الحسابات (تسجيل الدخول، حفظ قوائم الفصول على الحساب).
- الباقات والدفع وقفل الأدوات المدفوعة.
- أدوات جديدة.
